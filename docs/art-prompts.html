Sigilbound Art Prompts

Prompts for Google Gemini's image generation, covering all 21 beasts in their base, evolved and final forms. These make stand-in art until you have a commissioned artist.

How to use these

  1. Start each beast in a fresh Gemini chat. Paste its base-form prompt. Every base prompt already includes the shared style block, so all 21 beasts come out looking like one game.
  2. Regenerate until one feels right. Ask for 2–3 more tries if needed. Once you love one, keep it as your style reference: attach it to later base prompts and add "Match the art style of the attached image."
  3. Evolve in the same chat. Paste the evolved-form prompt. It asks Gemini to edit the image it just made, which keeps the face and colors consistent. Then do the same with the final-form prompt.
  4. Save each image with the file name shown (for example cindermaw_0.png, where 0, 1 and 2 are the form number). When the game gets image support it can pick them up by name.
  5. Remove the backgrounds. Gemini doesn't reliably make transparent images, so the prompts ask for a plain flat background that's easy to cut out with a background-removal tool.

Getting consistent results

Name driftIf Gemini adds text or a card frame, reply "Remove all text and borders, keep the creature identical."
Wrong directionThe beasts should face right. If one faces left, ask Gemini to mirror it, or flip it yourself. The game mirrors enemies automatically.
Style wanderingAttach your best image and add "Match the art style, line weight and shading of the attached image exactly."
Evolution looks like a different creatureReply "Keep the same face, eye shape and color palette as the previous image; only add the listed changes."

Before any of this art ships in a released game, check Google's current terms for commercial use of Gemini images. Also keep in mind that purely AI-generated images generally can't be copyrighted in the US, so treat these as temporary art rather than the final look of the game.
